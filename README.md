# VRBit - Virtual Reality Solar System Model

## Overview
VRBit is a Virtual Reality (VR) web application that demonstrates an interactive 3D model of the Solar System. The model is rendered using WebVR and A-Frame, providing an engaging educational experience for users to visualize and interact with the solar system.

## Features
- **3D Solar System**: Explore the solar system with realistic 3D models of planets.
- **VR Mode**: Supports Virtual Reality (VR) headsets for a fully immersive experience.
- **Interactive**: Clickable planets for detailed information.
- **Real-time Updates**: Smooth animations that show the rotation of planets.
